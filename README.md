# event-echo

일상에서 생기는 크고 작은 소식.
출산, 축하, 기념일 같은 순간들을 모바일 카드나 청첩장 같은 형태의 웹 페이지로 만들어, 가족과 친구들에게 링크 하나로 쉽게 공유할 수
있게 해주는 서비스 모음이다. 서비스마다 특정 이벤트에 맞춘 페이지 생성 도구(소유자용)와
방문자가 보는 공유 화면을 독립적으로 제공한다.

## 구성 서비스

### 1. [gender-reveal](gender-reveal/) — 젠더리빌
아기의 성별을 지인들에게 재미있게 공개하는 이벤트 페이지 서비스. 예비 부모가 태명,
공개 예정 일시, 출산 예정일 등을 담아 페이지를 만들어 링크를 공유하면, 방문자는
성별을 맞춰보고 결과를 확인한 뒤 축하 메시지를 남길 수 있다. 백엔드는 Spring Boot,
프론트엔드는 Next.js 정적 export로 구성돼 있다. 자세한 내용은
[gender-reveal/README.md](gender-reveal/README.md) 참고.
