# 젠더리빌

## 개요
아기의 성별을 지인들에게 재미있게 공개하는 이벤트 페이지 서비스.
소유자(부모)가 페이지를 만들어 링크를 공유하면, 방문자(게스트)는 성별을 맞춰보고 결과를 확인한 뒤 축하 메시지를 남길 수 있다.

참고사이트([hyeminpark9105.github.io/baby-gender-reveal](https://hyeminpark9105.github.io/baby-gender-reveal/))는
`config.js`에 성별(`boy`/`girl`/`secret`)과 태명을 정적으로 입력해두는 1인용 정적 페이지로,
인트로 연출 → 리빌 화면만 존재하고 게스트 참여(맞추기, 방명록)나 관리자 기능은 없다.
본 서비스는 이 연출 구조를 기반으로 하되, **게스트 참여형 맞추기**, **방명록**, **관리자 대시보드**, **보관주기**를 추가한다.

## 기능 아이템 정의

### 1. 페이지 작성
- 아기 태명 입력
- 실제 성별 입력 (정답, 공개 전까지 비공개로 저장)
- 공개 예정 일시 설정 (선택) — 설정 시 그 전까지는 "비밀" 상태로 노출
- 출산 예정일 입력 (선택사항) — 입력 시 연도 기준으로 **띠(말띠/용띠/양띠 등 12지신)를 자동 계산**해 아래 두 화면에 노출, 미입력 시 관련 문구/캐릭터 이미지는 노출하지 않음
  1. 인트로 화면: 타이핑 문구 옆/위에 해당 띠의 12지신 캐릭터 정지 이미지 노출
  2. 결과 확인 화면: 띠 문구(예: "말띠둥이가 찾아왔어요!")와 함께 동일한 12지신 캐릭터 이미지 노출
  - 12지신 캐릭터 일러스트 12종 세트 제작 필요
- 축하 메시지 문구 커스터마이징 (예: "왕자님이 찾아왔어요!" / "공주님이 찾아왔어요!")
- 테마 선택 (색상: 남아=블루 계열, 여아=핑크 계열 / 일러스트 스타일)
- 결과 확인 리빌 연출 테마 선택 — 아래 3종 중 택1 (자세한 내용은 [화면 프로세스 – 3. 결과 확인](#3-결과-확인) 참조)
  1. 서프라이즈 박스
  2. 젠더 리빌 케이크
  3. 젠더 리빌 풍선
- 배경음악(BGM) — 고정 제공되는 곡 중 사용 여부만 선택 (커스텀 업로드 불가)
- 미리보기 — 발행 전, 선택한 테마/문구/BGM이 실제 결과 화면과 동일하게 보이는 미리보기 제공 후 발행

### 2. 웹주소 생성
- 페이지별 고유 URL 자동 발급 (예: `/g/{code}`)
- 커스텀 슬러그 입력 지원 — 소유자가 원하는 문자열로 URL 지정 가능 (중복 확인 후 사용, 미입력 시 자동 발급 코드 사용)

### 3. 공유
- 링크 복사
- 카카오톡 등 SNS 공유는 API 연동 없이, 복사한 링크를 소유자가 직접 SNS/메신저에 붙여넣는 방식 (OG 태그로 미리보기 카드는 노출 — 참고사이트의 `og:title`/`og:image` 방식 참조)
- 페이지 발행 시, 발행된 링크를 **소유자 본인 이메일로 자동 발송** (기록/백업용, 게스트에게 초대 메일을 보내는 기능은 아님 — 게스트 공유는 소유자가 링크 복사/SNS로 직접 수행)
- QR 코드 생성 (선택)

### 4. 결과 대시보드 (admin)
- 소유자 전용 관리 화면
- **인증 방식: 매직링크** — 이메일 주소 입력 → 로그인 링크가 담긴 이메일 발송 → 링크 클릭으로 로그인 (비밀번호 없음)
- 방문자 수 / 맞추기 참여자 수 통계
- 게스트 맞추기 결과 집계 (boy 예측 수 vs girl 예측 수)
- 축하 메시지(방명록) 목록 조회, 노출/숨김 및 삭제(모더레이션)
- 공개 예정 일시 수정, 정답 확정 여부 확인
- 보관주기 만료로 열람 제한된 페이지의 **연장** 처리 (로그인 후에만 가능, **1회에 한해 30일 연장** — 재연장 불가)

### 5. 보관주기
- 페이지 생성일 기준 **30일** 후 자동 만료
- 만료 임박 시 소유자에게 안내(이메일/알림)
- 만료 시 데이터는 **삭제하지 않고 보관**하며, 페이지 열람만 제한(비공개 처리)
- 소유자가 로그인하면 대시보드에서 **1회에 한해 30일 연장** 가능 (최대 총 60일). 연장을 이미 사용한 페이지는 이후 계속 열람 제한 상태로 유지(데이터는 삭제하지 않음)

## 화면 프로세스

### 1. 인트로
- 진입 시 오버레이 연출: 물음표(?) 파티클이 화면에 떠다니는 애니메이션 (참고사이트 방식)
- "두근두근... {태명}는 딸일까요, 아들일까요?" 문구가 한 글자씩 타이핑되어 표시
  - 출산 예정일을 입력한 경우, 문구 옆/위에 해당 연도의 12지신 캐릭터 정지 이미지를 함께 노출 (미입력 시 생략)
- 일정 시간 후 오버레이 페이드아웃 → 다음 화면으로 전환
- **공개 예정 시각 이전에 접근한 경우**: 리빌 대신 "비밀" 상태 화면으로 전환
  - "아직 {태명}의 성별은 비밀이에요" 문구 + 선물상자 + 물음표 장식
  - "공개 시간이 되면 이 페이지가 바뀔 예정이에요" 안내 문구
  - (참고사이트의 `secret` 상태를 그대로 차용, 카운트다운 표시 추가 검토)
- **보관주기 만료로 열람 제한된 경우**: 만료 안내 화면으로 전환 (연장은 소유자 로그인 후 대시보드에서만, 1회 한정으로 가능)

### 2. 선택 (성별 맞추기) — 참고사이트에는 없는 신규 기능
- 게스트에게 "당신의 예상은?" 질문과 함께 boy/girl 선택 버튼 제공
- 선택은 1회만 가능 — **쿠키 기반**으로 중복 참여 방지 (로그인 불필요)
- 선택 완료 시 다음 화면(결과 확인)으로 이동

### 3. 결과 확인
- 소유자가 페이지 작성 시 선택한 리빌 연출 테마 3종 중 하나로 표시 (모두 1차 출시 범위에 포함, 에셋 제작 필요)
  1. **서프라이즈 박스** (선물상자 + 토퍼 통합): 상자 리드가 열리며 안에서 풍선이 떠오르고, 문구가 적힌 토퍼가 함께 올라오는 연출 (참고사이트의 gift-box 오픈 애니메이션에 풍선·토퍼 요소를 결합)
  2. **젠더 리빌 케이크**: 케이크를 자르는 연출 → 시트 안쪽 크림/과일 색상(분홍=딸, 파랑=아들)으로 성별 공개
  3. **젠더 리빌 풍선**: 큰 풍선이 터지며 안에서 색색의 작은 풍선/컨페티가 쏟아지는 연출
- 공통 리빌 씬 요소
  - 남아: 블루 톤, 아기 일러스트 + 운동화/자동차 장식, 하트(♥) 파티클, "왕자님이 찾아왔어요!"
  - 여아: 핑크 톤, 아기 일러스트 + 드레스/곰인형 장식, 하트(♥) 파티클, "공주님이 찾아왔어요!"
  - 상단 리본 배너에 "축하합니다" 문구
  - 출산 예정일을 입력한 경우, 연도 기준으로 계산한 띠 문구와 12지신 캐릭터 이미지를 함께 노출 (예: "말띠둥이가 찾아왔어요!" + 말 캐릭터 이미지, 인트로에서 쓰인 것과 동일한 이미지) — 미입력 시 생략
  - BGM 사용 설정 시, 결과 확인 화면 진입과 동시에 **무음(muted) 상태로 자동재생** 시작 (인트로/선택 화면은 무음) — 화면 우상단 고정 아이콘으로 음소거 해제 가능하며, 해제 상태는 브라우저에 저장되어 다음 재방문 시에도 유지
- 게스트 본인이 앞서 선택한 예측과 실제 결과를 비교해 정답/오답 표시

### 4. 축하글 남기기
- 이름(또는 닉네임) + 축하 메시지 입력 폼
- 등록 후 방명록 목록에 노출 (최신순)
- 닉네임으로 작성자를 구분하므로 별도의 중복 작성 방지는 두지 않음 (여러 번 남길 수 있음)
- 부적절한 내용 신고/숨김 기능 (관리자 대시보드에서 처리)

## 페이지 상태 정의
| 상태 | 설명 | 노출 화면 |
|---|---|---|
| `secret` | 공개 예정 시각 이전, 정답 비공개 | 비밀 안내 화면 |
| `open` | 공개 가능, 게스트 참여 가능 | 인트로 → 선택 → 결과 → 방명록 |
| `expired` | 보관주기(30일) 만료, 데이터는 보관되나 열람 제한 | 만료 안내 화면 (소유자 로그인 후 1회 한정 30일 연장 시 `open`으로 복귀) |

## 참고사이트 대비 차별점
- 정적 1인용 리빌 페이지 → 게스트 참여(맞추기)형 페이지로 확장
- 방명록(축하글) 기능 추가
- 소유자용 관리자 대시보드(통계, 모더레이션, 연장) 추가
- 페이지 보관주기(30일 자동 만료, 1회 연장, 열람 제한) 정책 추가
- 서프라이즈 박스/케이크/풍선 등 3종 리빌 연출 테마 선택지 추가
- 출산 예정일 기반 띠(12지신 캐릭터 이미지 포함) 자동 노출, 고정 BGM 추가
- 커스텀 슬러그(웹주소) 직접 지정 기능 추가
- `config.js` 수동 편집 방식 → 웹 UI 기반 페이지 작성 플로우로 대체
