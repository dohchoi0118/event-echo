- "AI(Claude)로 작업/결과물을 만드는 상황이니 별도 디렉토리로 관리해달라"는 요청에 따라

### 12. `~/.claude/projects/...` 경로는 통합하지 않기로 결정
- "작업 영역은 한 곳이어야 한다"는 요청으로 Claude Code 앱의 세션 메모리 경로
  (`~/.claude/projects/-Users-hanwha-Workspace-event-echo-gender-reveal/`)도 `ai-work/`로 합쳐야 하는지 확인
- 해당 경로를 조사한 결과, 이 세션의 대화 로그(`.jsonl`)만 존재하고 `memory/` 폴더는 아직 생성되지 않은 상태를 확인
- 이 경로는 저장소 밖(홈 디렉토리)에 있는 **Claude Code 앱 자체의 로컬 상태**(세션 로그, 크로스세션 메모리)이며,
  경로도 앱이 프로젝트 디렉토리 기준으로 자동 관리하므로 옮겨도 실제로는 재사용되지 않고,
  대화 전문/개인 협업 메모가 git 저장소에 커밋될 위험만 있음을 설명
- 사용자가 이해하고 통합하지 않기로 결정 → 대신 [CLAUDE.md](../CLAUDE.md)에 "이 경로는 프로젝트 산출물이 아니며
  저장소에 포함되지 않는다"는 안내 한 줄 추가

### 13. 의미 없는 빈 디렉토리 `context/`, `memory/` 삭제
- 실제 Claude Code 메모리/세션 저장소는 `~/.claude/projects/...`(저장소 밖)에 있다는 게 확인되자,
  `ai-work/context/`, `ai-work/memory/`(11번 항목에서 이동해온 빈 디렉토리)는 쓰임이 없다는 점을 사용자가 지적
- 삭제 직전 재확인해도 여전히 완전히 빈 디렉토리(파일 없음, git 미추적)임을 확인 후 삭제
- 현재 `ai-work/`에는 `Requirements.md`, `WORKLOG.md`, `wireframe/`만 남음
