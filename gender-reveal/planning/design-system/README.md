# 젠더리빌 디자인 시스템

컬러 · 타이포그래피 · 스페이싱 · 모서리 토큰을 담은 Claude Design System 아티팩트의 소스 사본입니다.

**미리보기(라이브 링크)**: https://claude.ai/artifact/2VxooVQJLMgfKfhgqiHTyD

`project/`는 Claude 아티팩트(Design System) 전용 포맷이라 이 저장소만으로는 렌더링되지 않으며,
위 라이브 링크에서만 실제로 확인/편집할 수 있습니다. 이 폴더는 그 소스를 버전 관리 목적으로 보관하는 사본입니다.

## 구성

- `project/tokens.json` — 컬러(아이보리 베이스 + 남아/여아 강조색 + 코럴 CTA), 타이포(Jua 디스플레이 +
  Noto Sans KR 본문), 스페이싱(4px 스케일), 라운드(sm/md/full) 토큰
- `project/README.md` — 브랜드 톤 및 토큰 사용 원칙 (컬러/타이포/여백)
- `project/components/Cover/preview.html` — 커버 (팔레트 + 패턴으로 브랜드를 보여주는 표지)

## 다음 단계

이 토큰을 기반으로 (1) 12지신 캐릭터 등 일러스트 자산, (2) 와이어프레임 9개 화면의 고충실도 디자인을
만들 예정입니다.
