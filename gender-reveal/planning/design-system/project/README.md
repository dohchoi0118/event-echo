# 젠더리빌 디자인 시스템

아기의 성별을 지인들에게 재미있게 공개하는 이벤트 페이지, "젠더리빌"을 위한 디자인 시스템입니다.
[요구사항 문서](https://github.com/dohchoi0118/event-echo/blob/main/gender-reveal/planning/Requirements.md)와
[와이어프레임](https://claude.ai/artifact/FnyMrMcbQ8mYLnyHVRfoRV)을 기반으로 만들었습니다.

## 브랜드 톤

따뜻하고 포근한 축하의 순간을 담습니다. 화려하거나 자극적인 톤보다는, 아이보리 배경 위에
파스텔 블루·핑크가 은은하게 어우러지는 손그림 느낌을 지향합니다.

## 컬러 사용 원칙

- `accent-boy` / `accent-girl`은 **리빌 결과를 보여줄 때만** 사용합니다. 결과가 공개되기 전 화면
  (인트로, 선택)이나 공용 UI(버튼, 링크, 폼)에는 사용하지 않습니다 — 성별이 정해지기 전에
  미리 색으로 암시하지 않기 위함입니다.
- 버튼 · CTA · 링크 등 실제 인터랙션 요소는 항상 `accent-primary`(코럴)를 사용합니다. 성별과
  무관하게 일관된 액션 색상을 유지합니다.
- `danger`는 관리자 대시보드의 삭제·숨김 같은 파괴적 액션에만 사용합니다.

## 타이포그래피 사용 원칙

- `display-*`(Hi Melody)는 리빌 순간의 타이틀, 리본 배너, 인트로 문구처럼 **짧고 임팩트 있는 문구**에만
  사용합니다. 통통 튀는 손글씨체라 긴 본문에는 쓰지 않습니다.
- 그 외 모든 텍스트(본문, 폼, 방명록, 관리자 화면)는 `sans`(Noto Sans KR)를 사용합니다.

## 여백 · 모서리

- 간격은 `space-1`~`space-5`(4px 배수) 스케일을, 모서리는 `radius-sm` / `radius-md` / `radius-full`
  세 단계를 일관되게 사용합니다. 원형 버튼이나 배지처럼 완전히 둥근 모양은 항상 `radius-full`을 씁니다.

## 일러스트 자산

참고 사이트([hyeminpark9105.github.io/baby-gender-reveal](https://hyeminpark9105.github.io/baby-gender-reveal/))의
실제 캐릭터 이미지를 확인한 결과, 기존에 적용했던 `guide01.md`/`guide02.md`의 굵은 검은 외곽선
스타일이 참고 사이트의 실제 그림체(부드러운 그라데이션 음영 + 흰색 스티커 외곽선)와 다르다는 점을
확인하고, **guide01/02의 외곽선 규칙은 폐기**했습니다. 현재 스타일 규칙은 다음과 같습니다.

- 모든 실루엣은 `illus-sticker`(흰색) 외곽선으로 두릅니다 — 배경에서 스티커처럼 떨어져 보이는
  효과. 단, 흰색/아이보리 계열처럼 외곽선과 색이 겹치는 요소는 흰색 대신 연한 웜그레이 선
  (`#E3D8C2` 등)으로 대체해 시인성을 확보합니다.
- 주요 면적(머리/몸통)은 단색 대신 **부드러운 방사형·선형 그라데이션**(밝은 톤 → 원래 `illus-*`
  토큰 색)으로 채워 입체감을 줍니다.
- 눈동자는 순수 검정 대신 `illus-eye`(다크브라운) + 작은 흰색 하이라이트 점, 입은 `illus-mouth`
  (테라코타브라운) 얇은 곡선을 사용합니다.
- 캐릭터 하단에는 `illus-shadow` 8~15% 불투명도의 타원으로 은은한 그림자를 깔아 공중에 뜬
  느낌을 줍니다.
- 그림자·그라데이션 금지, 얼굴 아이콘 전용 같은 guide01/02의 제약은 더 이상 적용하지 않습니다.

- **12지신** (12종) — 출산 예정일 기준 띠에 맞춰 인트로·결과 확인 화면에 노출. 동물별 실루엣
  형태(귀/뿔/무늬 등)는 이전 굵은 외곽선 버전에서 그대로 이어받고, 채색 기법만 위 스타일로 교체
- **캐릭터** (2종) — 아기 남아/여아. 마찬가지로 실루엣은 유지하고 채색만 교체
- **리빌테마** (6종) — 결과 확인 화면의 3가지 리빌 테마(서프라이즈 박스/케이크/풍선) × 남아·여아,
  `accent-boy`/`accent-girl` 토큰으로 색상 분기. 참고 사이트에 없는 자산이라 위 스타일 규칙에
  맞춰 직접 디자인
- **소품** (4종) — 운동화·자동차·드레스·곰인형. 참고 사이트의 실제 보조 이미지(`boy-shoes.png`,
  `toy-car.png`, `girl-dress.png`, `teddy-bear.png`)와 대응되는 성별 무관 범용 장식 소품

각 파일과 색상 매핑은 해당 에셋 그룹의 README를 참고하세요.
