# 리빌테마

결과 확인 화면에서 오너가 선택한 3가지 리빌 테마(서프라이즈 박스 / 케이크 / 풍선)를 표현하는
메인 그래픽입니다. 참고 사이트(hyeminpark9105.github.io/baby-gender-reveal)에는 정의가 없는 자산이라,
12지신·캐릭터와 동일한 v2 스타일(그라데이션 채색 + 흰색 스티커 외곽선 + 은은한 그림자)로 직접
디자인했습니다. 흰색/아이보리 면적이 큰 케이크 자산은 흰색 스티커 외곽선 대신 웜그레이 선
(`#E3D8C2`)을 사용해 배경과의 대비를 확보했습니다.

성별별로 파일을 분리해 `accent-boy`/`accent-boy-soft`(남아) · `accent-girl`/`accent-girl-soft`(여아)
토큰만 다르게 적용했습니다 — 두 토큰은 원래 "리빌 결과를 보여줄 때만" 쓰도록 정의돼 있어, 이
그룹이 정확히 그 용도입니다.

## 파일 목록

| 파일 | 설명 | 주요 색상 |
| --- | --- | --- |
| `서프라이즈박스-남아.svg` / `-여아.svg` | 뚜껑이 기울어 열린 선물 박스, 위로 떠오르는 그라데이션 풍선과 끈, 하트 마크가 있는 깃발 토퍼, 컨페티 조각 | `accent-boy`/`accent-girl` 그라데이션 |
| `케이크-남아.svg` / `-여아.svg` | 2단 케이크(아이보리 크림 + 컬러 드립 라인), 깃발 토퍼, 스프링클, 접시에 놓인 조각 케이크 | 아이보리 크림, `accent-boy`/`accent-girl` |
| `풍선-남아.svg` / `-여아.svg` | 글로시 하이라이트가 있는 큰 풍선과 뒤에서 터지는 별 모양 팝-버스트, 미니 풍선 2개, 컨페티 조각 | `accent-boy`/`accent-girl` 그라데이션, `accent-primary` |

## 사용 규칙

- 이 그룹의 파일은 결과 확인 화면에서만 사용합니다. 인트로·선택 화면처럼 성별이 아직 공개되지
  않은 화면에는 절대 노출하지 않습니다(디자인 시스템 컬러 사용 원칙과 동일).
- 남아/여아 두 파일은 형태(패스)가 완전히 동일하고 색상 토큰만 다릅니다 — 신규 색상을 추가하지
  않고 기존 `accent-*` 토큰을 재사용합니다.
