# 소품

성별과 무관하게 쓸 수 있는 범용 장식 소품 4종입니다. 참고 사이트(hyeminpark9105.github.io/baby-gender-reveal)의
실제 보조 이미지(`boy-shoes.png`, `toy-car.png`, `girl-dress.png`, `teddy-bear.png`)와 대응되는
구성이며, 12지신·캐릭터·리빌테마와 동일한 v2 스타일(그라데이션 채색 + 흰색 스티커 외곽선 + 은은한
그림자)로 직접 디자인했습니다.

## 파일 목록

| 파일 | 설명 | 주요 색상 |
| --- | --- | --- |
| `운동화.svg` | 측면에서 본 아기 운동화. L자형 실루엣(발목/뒤축 + 발끝) + 별도 밑창 띠 + 흰색 신발끈 2줄 + 아일릿 포인트. 초기 곡선형 시도들이 신발로 읽히지 않아, 아이콘 관례에 맞춘 단순 실루엣으로 재설계 | `accent-boy` 그라데이션 |
| `자동차.svg` | 아기용 장난감 자동차. 둥근 차체 + 지붕 + 앞유리 + 큰 바퀴 2개 + 헤드라이트 | `accent-boy` 그라데이션 |
| `드레스.svg` | 아기 드레스. A라인 스커트 + 라운드 넥 보디스 + 리본 칼라 + 단추 장식 | `accent-girl` 그라데이션 |
| `곰인형.svg` | 곰돌이 인형. 둥근 얼굴 + 안쪽 귀 + 몸통 + 팔다리(원형) | `illus-dog-brown` 그라데이션(몸통), `illus-skin`(주둥이) |

## 사용 규칙

- 성별 테마에 종속되지 않는 범용 자산이라 특정 화면 전용 규칙은 없습니다. 페이지 꾸미기 등
  장식 목적으로 자유롭게 활용합니다.
- `운동화.svg`는 시각 검수 중 두 차례 재설계를 거쳤습니다(첫 시도는 뭉뚱그려진 덩어리처럼 보였고,
  두 번째 시도도 토스터처럼 보여 신발로 읽히지 않았습니다). 이후 SVG를 수정할 때도 좌표만 보고
  판단하지 말고 실제 렌더링으로 형태를 확인하세요.
