# 고충실도 화면 디자인

[디자인 시스템](../design-system/README.md)의 토큰과 일러스트 자산을 적용한 고충실도 화면
목업입니다. Claude Design 캔버스로 제작했으며, 소스 사본은 `project/`에 있습니다.

라이브 링크: https://claude.ai/artifact/9HpcjtbaJNY35E83RVc62n

## 포함된 화면 (9개)

[Requirements.md](../Requirements.md)의 화면 프로세스와 [와이어프레임](../wireframe/README.md)의
레이아웃을 그대로 따르되, 실제 컬러·타이포·일러스트로 완성했습니다.

| 파일 | 화면 | 비고 |
|---|---|---|
| `Main.dc.html` | ① 인트로 | 두근두근 타이핑 문구 + 12지신(예시: 말띠) 캐릭터, 클릭 시 선택 화면으로 이동 |
| `Select.dc.html` | ② 선택 (성별 맞추기) | 리빌 전 화면이라 남아/여아 버튼 모두 무채색 — 컬러로 성별을 미리 암시하지 않음 |
| `Result_Box.dc.html` | ③ 결과 확인 · 서프라이즈 박스 | 예시: 아들(남아) 리빌, 말띠, 예측 오답 케이스. 클릭 시 축하글 화면으로 이동 |
| `Guestbook.dc.html` | ④ 축하글 남기기 | 작성 폼 + 등록된 메시지 목록 예시 |
| `Result_Cake.dc.html` | 결과 확인 테마 변형 · 케이크 | 예시: 딸(여아) 리빌, 양띠, 예측 정답 케이스 |
| `Result_Balloon.dc.html` | 결과 확인 테마 변형 · 풍선 | 예시: 아들(남아) 리빌, 용띠, 예측 정답 케이스 |
| `Secret.dc.html` | 비밀 상태 (secret) | 공개 예정 시각 이전 진입 시 노출, 중립 톤(성별 색상 미사용) |
| `Expired.dc.html` | 만료 안내 (expired) | 보관주기 30일 만료 후 노출, 소유자 로그인 CTA |
| `Admin.dc.html` | 관리자 대시보드 | 데스크톱(1280×800) 전용, 통계/방명록 관리/보관주기 연장 |

## 예시로 사용한 콘텐츠

실제 데이터가 없는 디자인 단계라, 태명 "뽀튼이" 기준으로 하나의 일관된 시나리오를 예시로 채웠습니다.
- 메인 플로우(인트로 → 선택 → 결과 확인 · 서프라이즈 박스 → 축하글): 실제 성별 **아들**, 태어날 해 **말띠**
- 케이크 변형: 실제 성별 **딸**, **양띠**로 별도 예시
- 풍선 변형: 실제 성별 **아들**, **용띠**로 별도 예시

이 배정은 [와이어프레임](../wireframe/README.md)에서 쓰인 예시 값을 그대로 이어받았습니다.

## 디자인 원칙 적용

- `accent-boy`/`accent-girl`은 결과 확인 화면(및 그 테마 변형)에만 사용 — 인트로·선택·비밀 상태
  화면은 전부 무채색으로 유지해 성별을 미리 암시하지 않습니다.
- 리본 배너, 인트로 문구, 리빌 타이틀에만 `display`(Hi Melody) 폰트를 쓰고 나머지는 전부
  `sans`(Noto Sans KR)입니다.
- 버튼·CTA는 전부 `accent-primary`(코럴) — 성별 테마 화면 안에서도 CTA 색은 바뀌지 않습니다.
- 비밀/만료 화면의 장식 아이콘(선물상자, 느낌표)은 젠더 일러스트 세트를 쓰지 않고 별도의
  중립 톤 인라인 SVG로 그렸습니다 — 아직 성별이 공개되지 않았거나 연장 대기 중인 상태이므로.
